Archive, split panes, and right-click menus - the console grows up.

OpenRemote is one desktop window for the coding-agent harnesses on your
machine - Claude Code, Codex, Grok Build, Pi Agent, OpenCode and
Antigravity - run side by side. A Rust daemon wraps the harness CLIs and
serves the console over localhost; the desktop app ships the daemon
inside, so nothing leaves the machine. No telemetry.

## Archive

A finished chat can leave the sidebar without leaving the record.
Right-click its row and Archive: it's out of the list, transcript kept
whole, and still live on its other devices - archiving is a view
preference of the computer you're on; the daemon's chats are untouched.
Settings has the Archived chats section; restore whenever you want it
back. Nothing is ever deleted.

## Split panes

Up to four panes in one window: a Local chat beside a Cloud one, two
threads you're comparing, a fresh composer next to the work. Right-click
a chat in the sidebar and open it in a new split - left, right, above or
below - or use a pane's own split buttons. Panes are resizable; any
pane but the first can be closed; the first carries the window's own
navigation, so a window always has somewhere to go.

## Right-click menus

The sidebar's rows and the main area answer the right-click: open a chat
in a split from the sidebar, split or close a pane from the main area.
(Plus Copy title - the small things matter.)

## The transcript scrolls, fixed

On long chats the transcript could stop scrolling - the columns above
it could shrink below their content and push the scroll out of reach.
The layout holds; the transcript scrolls.

## Local after Cloud, aimed right

Switching from the Cloud tab back to Local kept the remote machine's
harnesses in New chat - and a chat sent from the Local tab would have
run on that remote. The mode switch now starts the machine choice
over: a Local chat runs on this computer, with this computer's
harnesses.

## Install

- **Android:** open the APK and let it install; the phone asks once for
  permission to install from the source you downloaded it from. The
  desktop bundles are unsigned; the APK is signed.
- **Windows:** run the installer. The daemon starts with the app; the
  token handshake is automatic.
- **Linux:** `chmod +x` the AppImage and run it, or install the `.deb`.
