OpenRemote on a phone, and a fix for Cloud projects.

OpenRemote is one desktop window for the coding-agent harnesses on your
machine - Claude Code, Codex, Grok Build, Pi Agent, OpenCode and
Antigravity - run side by side. A Rust daemon wraps the harness CLIs and
serves the console over localhost; the desktop app ships the daemon
inside, so nothing leaves the machine. No telemetry.

## Android

The console is now an app. Sign in with your moreweb account and your
machines appear on the phone: every synced chat, readable offline, and
runnable live.

- Sign-in goes through the browser and lands back in the app by itself.
- Every synced chat is mirrored and readable, online or off; a machine
  that goes offline keeps its chats listed and readable.
- Start a chat on a machine - the folder picker, the harness, the model,
  all from the phone - and steer it live: prompts, interruptions,
  approvals.
- A phone is a remote, never a machine: it cannot run harnesses, and no
  device ever offers to make it one.
- Android 8 or newer; one universal APK for all ABIs.

The phone talks to the moreweb cloud - sign-in, machines, synced chats.
The phone's sign-in needs a server-side update that is rolling out; if
your server does not have it yet, the app waits at its sign-in screen.
The desktop apps' Cloud mode works today and is not affected.

## Cloud projects, fixed

A Cloud desktop (or a phone) could not manage projects on a machine:
every call to register, list or remove one came back 403. The peer
routes now know `/projects`, so projects are manageable from any of your
devices.

## Install

- **Android:** open the APK and let it install; the phone asks once for
  permission to install from the source you downloaded it from. The
  desktop bundles are unsigned; the APK is signed.
- **Windows:** run the installer. The daemon starts with the app; the
  token handshake is automatic.
- **Linux:** `chmod +x` the AppImage and run it, or install the `.deb`.
